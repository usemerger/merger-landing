# Integration marks

The logos identify compatible services in a local design prototype. No customer, endorsement, or partnership claim is made.

- WhatsApp, Telegram, Signal, Discord, Instagram, Messenger, LINE, X, Gmail, Google Calendar, Google Meet, Claude: existing Simple Icons 16.35.0 assets, CC0-1.0. Package: https://github.com/simple-icons/simple-icons/tree/16.35.0/icons
- Slack: Simple Icons 14.15.0, https://raw.githubusercontent.com/simple-icons/simple-icons/14.15.0/icons/slack.svg . Official brand reference: https://slack.com/media-kit
- OpenAI: existing Merger asset from Simple Icons 14.15.0, https://github.com/simple-icons/simple-icons/blob/14.15.0/icons/openai.svg
- LinkedIn: existing Merger NetworkIcon.tsx path, reused unchanged.
- Docusign: existing Merger docusign.svg. ViewBox isolates the existing symbol from the full wordmark; paths are unchanged.

The banner applies a monochrome presentation using CSS. Brand rights remain with their respective owners. This section is platform-wide and is not a claim that every connection is available on every Merger client.
