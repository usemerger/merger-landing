- Merger diamond/GLB, inbox tray and vault: existing Merger workshop models and source animation code.
- Integration marks: see integration-SOURCES.md and LICENSE-simple-icons.md. Brand rights remain with the respective owners; compatibility is not an endorsement claim.

The original workshop, editable scenes and detailed generation/source receipts remain in the separate local design workspace. They are not deployed with account/admin code.
